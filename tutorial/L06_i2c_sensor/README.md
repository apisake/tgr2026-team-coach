# บทที่ 6 · I2C: ต่อเซ็นเซอร์ที่ไม่เคยเห็นภายใน 30 นาที

ผู้จัดจะให้เซ็นเซอร์ที่ยังไม่ระบุรุ่น บทนี้ฝึก **วิธีคิด** ไม่ใช่ท่องไลบรารี ใช้ SHT3x (อุณหภูมิ + ความชื้นสัมพัทธ์) เป็นตัวอย่าง เพราะเกี่ยวกับการตากและอบกาแฟโดยตรง

## เรียนอะไร

- **I2C** ใช้สาย 2 เส้น (SDA ข้อมูล, SCL สัญญาณนาฬิกา) ต่ออุปกรณ์หลายตัวบนบัสเดียว แยกกันด้วย **แอดเดรส 7 บิต**
- บนบอร์ดนี้ OLED (`0x3C`) อยู่บนบัสเดียวกับพอร์ต K2 แล้ว จึงต่อเซ็นเซอร์เพิ่มได้เลยถ้าแอดเดรสไม่ซ้ำ
- รูปแบบการคุยกับเซ็นเซอร์ I2C เกือบทุกตัว:
  1. `beginTransmission(addr)` → `write(คำสั่ง/register)` → `endTransmission()`
  2. รอเวลาวัดตาม datasheet
  3. `requestFrom(addr, n)` → `read()` n ไบต์
  4. รวมไบต์ ตรวจ CRC (ถ้ามี) แล้วแปลงเป็นหน่วยจริงด้วยสูตรใน datasheet
- `Wire.endTransmission()` คืน 0 เมื่อมีอุปกรณ์ตอบ (ACK) — I2C scanner ใช้หลักนี้

## สูตรต่อเซ็นเซอร์ใหม่ใน 30 นาที

| นาที | ทำอะไร |
|---|---|
| 0–5 | อ่านชื่อชิปบนบอร์ด เปิด datasheet (เตรียมไว้ในเครื่องก่อนไป) หา: ไฟเลี้ยง (3.3 V ได้ไหม), interface, แอดเดรส |
| 5–10 | ต่อสาย (VCC→3.3V, GND, SDA→21, SCL→22) แล้วรัน **I2C scanner** — ต้องเห็นแอดเดรสก่อนทำอย่างอื่น |
| 10–20 | มีไลบรารีในเครื่องไหม? ถ้ามี เปิด example ของไลบรารีแล้วแก้ขา ถ้าไม่มี ทำตามตาราง "คำสั่งวัด" และ "สูตรแปลงค่า" ใน datasheet แบบในสเก็ตช์นี้ |
| 20–25 | ตรวจค่าให้สมเหตุสมผล (อุณหภูมิห้อง ~25–35 °C, RH 40–80%) ลองเป่าลม/จับเซ็นเซอร์ดูว่าค่าเปลี่ยน |
| 25–30 | ห่อเป็นฟังก์ชัน `bool readXxx(float &...)` ที่คืน `false` เมื่ออ่านไม่ได้ แล้วนำไปรวมกับ firmware template (บทที่ 9) |

ถ้า scanner ไม่เจออะไร: สลับ SDA/SCL, ตรวจไฟเลี้ยง, ตรวจว่าโมดูลมีตัวต้านทาน pull-up หรือไม่ (บนบอร์ด IPST-WiFi มี pull-up 1.8k ให้แล้ว)

## ลองทำ

ต่อ SHT30/SHT31 ที่พอร์ต K2 แล้วอัปโหลด [L06_i2c_sensor.ino](L06_i2c_sensor.ino)
ถ้าไม่มี SHT3x ให้รันเพื่อดูผลสแกน (จะเห็น OLED ที่ `0x3C`) แล้วทำแบบฝึกหัดกับเซ็นเซอร์ I2C ที่มี

## แบบฝึกหัด

1. ทำให้สเก็ตช์ **หาแอดเดรสเอง**: ลอง `0x44` ถ้าไม่ตอบให้ลอง `0x45`
2. ใช้ **คำสั่ง heater** ของ SHT3x (ดู datasheet หัวข้อ Heater) เปิด 10 วินาทีแล้วสังเกตอุณหภูมิที่เพิ่ม — ทำไมเซ็นเซอร์ความชื้นต้องมี heater
3. เปลี่ยนเป็นเซ็นเซอร์อื่นที่มีในห้อง (เช่น BH1750 ที่ `0x23`: ส่งคำสั่ง `0x10` แล้วอ่าน 2 ไบต์ ÷ 1.2 = lux) โดยดู datasheet เท่านั้น จับเวลาว่าใช้กี่นาที
4. **ฝึกแบบวันแข่ง:** ให้เพื่อนเลือกเซ็นเซอร์ 1 ตัวที่คุณไม่เคยใช้ (I2C, 1-Wire DS18B20, หรือ HX711 load cell) แล้วจับเวลาจนส่งค่าออก Serial ได้ — เป้าหมาย ≤ 30 นาที
