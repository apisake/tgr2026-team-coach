# บทที่ 2 · PWM (LEDC): หรี่ไฟและเสียงแจ้งเตือน

## เรียนอะไร

- **PWM** คือการเปิด-ปิดขาเร็ว ๆ แล้วปรับสัดส่วนเวลาที่เปิด (duty cycle) — ใช้ปรับความสว่าง LED, ความเร็วพัดลมผ่าน MOSFET, มุม servo และสร้างเสียง
- ESP32 มีวงจร PWM ชื่อ **LEDC** ใน core 3.x ใช้แค่ 3 ฟังก์ชัน:

  | ฟังก์ชัน | ใช้ทำอะไร |
  |---|---|
  | `ledcAttach(pin, freq, bits)` | ผูกขากับ PWM เช่น 5000 Hz, 8 บิต (duty 0–255) |
  | `ledcWrite(pin, duty)` | ตั้ง duty |
  | `ledcWriteTone(pin, freq)` | เล่นเสียงความถี่ `freq` (0 = เงียบ) |

  > ตัวอย่างบนอินเทอร์เน็ตจำนวนมากยังใช้ API ของ core 2.x (`ledcSetup` + `ledcAttachPin` + เลข channel) ซึ่งคอมไพล์ไม่ผ่านบน core 3.x
- **ตัวเล่นเสียงแบบไม่บล็อก**: เก็บ "กำลังเล่นโน้ตที่เท่าไร ดังอยู่หรือเงียบอยู่ เริ่มเมื่อไร" แล้วให้ `loop()` เรียก `updateAlarm()` ทุกรอบ — ไฟยังหรี่ได้ต่อเนื่องระหว่างมีเสียง

## ฮาร์ดแวร์

- LED บนบอร์ด GPIO18, ลำโพงบนบอร์ด GPIO26 (ตามผล L00)
- ถ้ามี ZX-LED ให้ต่อพอร์ต K4 (GPIO19) — จะหรี่สลับกับ LED บนบอร์ด

## ลองทำ

อัปโหลด [L02_pwm_buzzer.ino](L02_pwm_buzzer.ino) — LED หรี่ขึ้นลงตลอด กด BUTTON แล้วได้ยินเสียงแจ้งเตือน 3 ครั้งโดยไฟไม่สะดุด

## แบบฝึกหัด

1. สร้างรูปแบบเสียงที่สอง `OK` (เสียงต่ำ-สูง สั้น ๆ) สำหรับ "บันทึกข้อมูลสำเร็จ"
2. ปรับ `PWM_BITS` เป็น 10 แล้วแก้ `map()` ให้ duty ไปถึง 1023 — สังเกตว่าหรี่ได้เนียนขึ้นที่ความสว่างต่ำหรือไม่
3. ให้ ZX-LED แทน "พัดลม" ที่มี 4 ระดับ (ปิด 25% 50% 100%) กด BUTTON เพื่อเปลี่ยนระดับ
4. คิดต่อกับโจทย์: ตู้อบที่ใช้พัดลม DC 12 V ต้องใช้อุปกรณ์อะไรคั่นระหว่าง GPIO กับพัดลม (ใบ้: MOSFET แบบ logic-level + ไดโอด flyback) และควรใช้ความถี่ PWM เท่าไรเพื่อไม่ให้มีเสียงหอน
