# บทที่ 4 · จอ OLED ด้วย U8g2

## เรียนอะไร

- จอบนบอร์ดเป็น OLED 128×64 ชิป **SSD1306** ต่อบัส I2C (SDA 21, SCL 22) ที่แอดเดรส `0x3C`
- ไลบรารี **U8g2** รองรับจอหลายร้อยรุ่นและมีฟอนต์ในตัว ใช้งานแบบ **full buffer**:
  1. `clearBuffer()` ล้างภาพใน RAM
  2. วาด/เขียนข้อความลง buffer (`drawStr`, `print`, `drawBox`, `drawFrame`, ...)
  3. `sendBuffer()` ส่งทั้งภาพไปที่จอครั้งเดียว — จอจึงไม่กระพริบ
- แอดเดรสใน U8g2 เป็นแบบ 8 บิต จึงต้องคูณ 2: `setI2CAddress(0x3C * 2)`
- พิกัด y ของ `drawStr` คือ **เส้นฐานของตัวอักษร** ไม่ใช่ขอบบน
- อย่าวาดจอทุกรอบ `loop()` — การส่ง 1 KB ผ่าน I2C ใช้เวลาราว 25 ms อัปเดต 5–10 ครั้ง/วินาทีก็พอ
- ฟอนต์ที่ใช้บ่อย: `u8g2_font_6x10_tf` (ข้อความเล็ก), `u8g2_font_logisoso22_tn` (ตัวเลขใหญ่ — `_tn` มีแค่ตัวเลข) ดูรายการทั้งหมดที่ [U8g2 font list](https://github.com/olikraus/u8g2/wiki/fntlistall)
- จอนี้แสดงภาษาไทยด้วยฟอนต์ทั่วไปไม่ได้ ให้ใช้ข้อความภาษาอังกฤษสั้น ๆ

## ลองทำ

อัปโหลด [L04_oled.ino](L04_oled.ino) แล้วหมุน KNOB — ตัวเลข mV และแถบกราฟจะเปลี่ยนตาม

ถ้าจอไม่ติด: ตรวจผลสแกน I2C ใน L00 ถ้าเป็น `0x3D` ให้แก้ `setI2CAddress(0x3D * 2)`

## แบบฝึกหัด

1. ทำ **กราฟเส้นย้อนหลัง** 128 จุดของค่า KNOB (เก็บค่าใน array แบบวงกลมแล้ววาดด้วย `drawPixel` หรือ `drawLine`)
2. ใช้ BUTTON สลับ **หน้าจอ 2 หน้า**: หน้าตัวเลขใหญ่ และหน้ากราฟ
3. ออกแบบหน้าจอสถานะของ "ตู้อบกาแฟ" ขนาด 128×64 ที่ต้องมี: อุณหภูมิ, ความชื้น, สถานะฮีตเตอร์/พัดลม, สถานะ Wi-Fi/MQTT และ `lot_id` — วาดบนกระดาษก่อนแล้วค่อยเขียนโค้ด (จะใช้ในบทที่ 9)
