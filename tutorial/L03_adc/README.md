# บทที่ 3 · ADC: อ่านแรงดันให้แม่นและนิ่ง

## เรียนอะไร

- ESP32 มี ADC 12 บิต (0–4095) สองชุด: **ADC1** (GPIO32–39) และ **ADC2** — ADC2 ใช้ไม่ได้ขณะเปิด Wi-Fi บอร์ด IPST-WiFi ให้พอร์ต analog K7–K10 (GPIO32–35) และ KNOB (GPIO36) อยู่บน ADC1 ทั้งหมด
- **Attenuation** กำหนดช่วงแรงดันที่วัดได้ ค่าเริ่มต้น `ADC_11db` วัดได้ราว 0.15–3.1 V และไม่เป็นเชิงเส้นที่ปลายทั้งสองข้าง
- `analogRead()` คืนค่าดิบซึ่งแต่ละชิปเพี้ยนต่างกัน ส่วน **`analogReadMilliVolts()`** ใช้ค่า calibration ที่โรงงานเขียนไว้ใน eFuse จึงได้ mV ที่ใกล้ความจริงกว่า — **ใช้ตัวนี้เสมอเมื่อต้องแปลงเป็นหน่วยจริง**
- ADC ของ ESP32 มี noise ราว ±10–30 mV จึงต้องกรอง:
  - **Median filter** ตัดค่ากระโดด (spike) ทิ้ง — เรียงค่า 9 ค่าล่าสุดแล้วเอาตัวกลาง
  - **EMA** (exponential moving average) `ema = α·x + (1−α)·ema` ทำให้เส้นเรียบ ใช้หน่วยความจำค่าเดียว
- Serial Plotter ของ Arduino IDE 2.x อ่านรูปแบบ `label:value,label:value` และวาดกราฟหลายเส้นได้

## ฮาร์ดแวร์

- KNOB บนบอร์ด (GPIO36)
- ZX-POT ที่พอร์ต K7 (GPIO32) ถ้ามี

## ลองทำ

อัปโหลด [L03_adc.ino](L03_adc.ino) แล้วเปิด **Tools → Serial Plotter**
หมุน KNOB ช้า ๆ เปรียบเทียบเส้น `mv` (มี noise), `median` (ไม่มี spike) และ `ema` (เรียบแต่ตามช้ากว่า)
`raw_x0.8` คือค่าดิบคูณ 0.8 ให้อยู่ในสเกลใกล้เคียงกันเพื่อดูความต่างระหว่างค่าดิบกับค่าที่ calibrate แล้ว

## แบบฝึกหัด

1. ปรับ `EMA_ALPHA` เป็น 0.02 และ 0.5 — อธิบายว่าแลกอะไรกับอะไร ถ้าเป็นเซ็นเซอร์อุณหภูมิตู้อบควรเลือกค่าไหน
2. หมุน KNOB ไปสุดทั้งสองข้าง ค่า mV ต่ำสุดและสูงสุดเท่าไร ตรงกับ 0 และ 3300 mV หรือไม่ ทำไม
3. ลองเปลี่ยนเป็น `ADC_0db` แล้วหมุน KNOB — ค่าอิ่มตัวที่เท่าไร เหมาะกับเซ็นเซอร์แบบไหน
4. เขียนฟังก์ชัน `int readMv(int pin, int n)` ที่อ่าน `n` ครั้งแล้วคืน median เพื่อใช้ซ้ำในบทถัดไป
