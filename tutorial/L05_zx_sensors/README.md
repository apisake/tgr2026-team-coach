# บทที่ 5 · เซ็นเซอร์ ZX ในชุด Activity Kit

## เรียนอะไร

- การต่อบอร์ด ZX ผ่านพอร์ต JST 3 ขา (S, +, GND) — เสียบได้ทางเดียว ไม่ต้องใช้ breadboard
- **แปลงแรงดันเป็นหน่วยจริงจาก datasheet**: ZX-MCP9701 ให้แรงดัน 400 mV ที่ 0 °C และเพิ่ม 19.5 mV ต่อ °C
  ```
  °C = (Vout[mV] − 400) / 19.5
  ```
  ช่วงวัด −40 ถึง +125 °C ความแม่นยำของตัวชิปราว ±2–4 °C จึงควร **calibrate offset** เทียบกับเทอร์โมมิเตอร์อ้างอิง
- **Two-point calibration**: ZX-SOIL ให้แรงดันเปลี่ยนตามความนำไฟฟ้าของดิน/วัสดุ ซึ่งไม่ใช่ % ความชื้นโดยตรง วัดแรงดันที่สภาพ "แห้ง" และ "เปียก" แล้วเทียบเชิงเส้นเป็น 0–100%
- **Threshold + การแจ้งเตือน**: เกินค่าที่กำหนด → ติด ZX-LED และส่งเสียง

## ฮาร์ดแวร์

| บอร์ด | พอร์ต | GPIO |
|---|---|---|
| ZX-MCP9701 (สายพร้อมหัวโลหะ) | K7 | 32 |
| ZX-SOIL | K8 | 33 |
| ZX-SWITCH01 | K3 | 5 |
| ZX-LED | K5 | 23 |

## ลองทำ

1. อัปโหลด [L05_zx_sensors.ino](L05_zx_sensors.ino) — จอแสดงอุณหภูมิและ % ความชื้น
2. **Calibrate ZX-SOIL**: กด ZX-SWITCH01 ค้างไว้ จอจะแสดงค่า mV ดิบ
   - จดค่าเมื่อหัววัดแห้งในอากาศ → `soilDryMv`
   - จดค่าเมื่อจุ่มในน้ำ (ไม่ให้น้ำโดนวงจร) → `soilWetMv`
   - แก้ค่าทั้งสองที่หัวไฟล์แล้วอัปโหลดใหม่
3. กำหัวโลหะของ ZX-MCP9701 ไว้ในมือ หรือจุ่มน้ำอุ่น จนเกิน 40 °C — ZX-LED ติดและมีเสียงเตือน
   (ถ้าไม่มีน้ำอุ่น ลดค่า `TEMP_ALARM_C` ลงชั่วคราวเพื่อทดสอบ)

## แบบฝึกหัด

1. เพิ่ม **offset calibration** ของอุณหภูมิ: วัดเทียบกับเทอร์โมมิเตอร์ แล้วบวกค่าแก้ไขในฟังก์ชัน `mcp9701C()`
2. ตอนนี้เสียงเตือนจะเปิด-ปิดถี่ ๆ ถ้าอุณหภูมิแกว่งอยู่ที่ 40.0 °C — แก้ด้วย **hysteresis**: เตือนเมื่อเกิน 40 °C แต่หยุดเตือนเมื่อต่ำกว่า 38 °C
3. ให้ ZX-SWITCH01 กดสั้น 1 ครั้ง = "ปิดเสียงเตือน 60 วินาที" (snooze) ขณะที่ ZX-LED ยังติดอยู่
4. **คิดต่อกับโจทย์ (R4 ในแผน):** ZX-SOIL วัด "ความชื้นของเมล็ดกาแฟสาร" ได้แม่นแค่ไหน ข้อจำกัดคืออะไร (ใบ้: ผิวสัมผัส ความหนาแน่น อุณหภูมิ) เครื่องวัดความชื้นเมล็ดพืชจริงใช้หลักการอะไร และถ้าต้องใช้เซ็นเซอร์ราคาถูกจะ calibrate กับวิธีอบแห้งอย่างไร
